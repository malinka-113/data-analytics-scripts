# data-analytics-scripts

Скрипты на Python для автоматизации рутинных задач аналитика данных и инженера хранилищ (DWH).

---

## 🛠 1. Утилита загрузки проверок кода (Code Review) в PostgreSQL

Скрипт для автоматической загрузки данных из Excel-файла с проверками кода в таблицу PostgreSQL на dev-окружении.

### 📋 Назначение
Скрипт решает задачу быстрой и надежной загрузки списка проверок (code review checks) из Excel-файла в базу данных. Это полезно для:
- Переноса справочника проверок между окружениями
- Массового обновления списка проверок
- Автоматизации рутинных операций по наполнению БД

### ⚙️ Требования
**Системные:**
- Python 3.7+
- Доступ к PostgreSQL (локальному или удаленному)
- Excel-файл с проверками в формате `.xlsx`

**Зависимости Python:**
- `pandas` — работа с табличными данными
- `psycopg2-binary` — драйвер для подключения к PostgreSQL
- `openpyxl` — чтение Excel-файлов
- `sqlalchemy` — ORM для работы с БД

### 🚀 Быстрый старт
**1. Установка зависимостей:**
pip install pandas psycopg2-binary openpyxl sqlalchemy

## 🔄 2. Парсер маппингов DWH (Word → Excel)

Автоматизированный инструмент для извлечения SQL-запросов и атрибутов из документов первичного маппинга (формат R08, Банк ВТБ) и построения матрицы соответствия атрибутов источника и целевой модели данных (ОВЮЛ).

### 📋 Назначение

Скрипт решает задачу быстрого анализа документов первичного маппинга и автоматического построения матрицы соответствия. Это полезно для:
- Ускорения обработки документов маппинга (секунды вместо часов ручной работы)
- Исключения человеческих ошибок при сверке атрибутов
- Автоматического учёта всех атрибутов из SELECT, JOIN и WHERE
- Формирования готового Excel-отчёта для использования в постановках

###  Что делает скрипт

1. **Извлекает SQL-запрос** из таблицы Word-документа (раздел 4.3 "Описание наборов данных")
2. **Парсит SQL** с разделением на блоки:
   - Атрибуты из SELECT (с учётом алиасов)
   - Атрибуты из JOIN ON (условия соединения)
   - Атрибуты из WHERE (фильтры)
3. **Автоматически извлекает правила маппинга** из таблицы атрибутов (раздел 4.5)
4. **Сопоставляет атрибуты** SQL с правилами маппинга по колонке П37 (Поле)
5. **Формирует Excel-отчёт** с полной матрицей соответствия

### ⚙️ Требования

**Системные:**
- Python 3.7+
- Доступ к файлам Word (`.docx`) с документами первичного маппинга

**Зависимости Python:**
- `pandas` — работа с табличными данными
- `python-docx` — чтение Word-документов
- `openpyxl` — запись Excel-файлов
- `re` — регулярные выражения (встроено в Python)

```bash
