## 🛠 1. Утилита загрузки проверок кода (Code Review) в PostgreSQL

Скрипт на Python для автоматической загрузки данных из Excel-файла с проверками кода в таблицу PostgreSQL на dev-окружении.

###  Назначение

Скрипт решает задачу быстрой и надежной загрузки списка проверок (code review checks) из Excel-файла в базу данных PostgreSQL. Это полезно для:
- Переноса справочника проверок между окружениями
- Массового обновления списка проверок
- Автоматизации рутинных операций по наполнению БД

### ⚙️ Требования

#### Системные требования
- Python 3.7+
- Доступ к PostgreSQL (локальному или удаленному)
- Excel-файл с проверками в формате `.xlsx`

#### Зависимости Python
Все зависимости устанавливаются автоматически при первом запуске скрипта:
- `pandas` — работа с табличными данными
- `psycopg2-binary` — драйвер для подключения к PostgreSQL
- `openpyxl` — чтение Excel-файлов
- `sqlalchemy` — ORM для работы с БД

## 🔄 2. Парсер маппингов DWH (Word → Excel)

Автоматизированный инструмент для извлечения SQL-запросов и атрибутов из документов первичного маппинга (Word) с последующим сопоставлением с правилами загрузки в хранилище данных.

### 📋 Описание

Скрипт разработан для автоматизации работы системного аналитика DWH. Он решает задачу быстрого анализа документов первичного маппинга (формат R08, используемый в банке ВТБ) и построения матрицы соответствия атрибутов источника и целевой модели данных (ОВЮЛ).

### Что делает скрипт:

1. **Извлекает SQL-запрос** из таблицы Word-документа (раздел 4.3 "Описание наборов данных")
2. **Парсит SQL** с разделением на блоки:
   - Атрибуты из SELECT (с учётом алиасов)
   - Атрибуты из JOIN ON (условия соединения)
   - Атрибуты из WHERE (фильтры)
3. **Автоматически извлекает правила маппинга** из таблицы атрибутов (раздел 4.5)
4. **Сопоставляет атрибуты** SQL с правилами маппинга по колонке П37 (Поле)
5. **Формирует Excel-отчёт** с полной матрицей соответствия

###  Преимущества

- ⚡ **Экономия времени**: обработка документа за секунды вместо часов ручной работы
- 🎯 **Точность**: исключение человеческих ошибок при сверке атрибутов
- 📊 **Полнота**: автоматический учёт всех атрибутов из SELECT, JOIN и WHERE
- 🔍 **Прозрачность**: чёткое разделение источников атрибутов (SELECT/JOIN/WHERE)
-  **Готовая документация**: результат сразу можно использовать в постановках

### ⚙️ Требования

- Python 3.7+
- Доступ к файлам Word (.docx) с документами первичного маппинга
- Установленные библиотеки (см. ниже)
