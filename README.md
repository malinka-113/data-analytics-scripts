# 🛠 Утилита загрузки проверок кода (Code Review) в PostgreSQL

Скрипт на Python для автоматической загрузки данных из Excel-файла с проверками кода в таблицу PostgreSQL на dev-окружении.

##  Назначение

Скрипт решает задачу быстрой и надежной загрузки списка проверок (code review checks) из Excel-файла в базу данных PostgreSQL. Это полезно для:
- Переноса справочника проверок между окружениями
- Массового обновления списка проверок
- Автоматизации рутинных операций по наполнению БД

## ⚙️ Требования

### Системные требования
- Python 3.7+
- Доступ к PostgreSQL (локальному или удаленному)
- Excel-файл с проверками в формате `.xlsx`

### Зависимости Python
Все зависимости устанавливаются автоматически при первом запуске скрипта:
- `pandas` — работа с табличными данными
- `psycopg2-binary` — драйвер для подключения к PostgreSQL
- `openpyxl` — чтение Excel-файлов
- `sqlalchemy` — ORM для работы с БД
